# Portfolio - Erika

## Autor
- **Nombre y apellido:** Erika

## Descripción
Portfolio web personal para presentar información sobre mí, mis habilidades y mis proyectos. Incluye las secciones de Inicio, Sobre mí, Proyectos y Contacto.

## Tecnologías utilizadas
- HTML
- CSS (Flexbox, Grid, Media Queries)
- JavaScript (eventos, funciones, DOM, validaciones)
- Git y GitHub

## Funcionalidades principales
- Menú de navegación a las distintas secciones del sitio.
- Sección "Sobre mí" con contenido que se puede mostrar u ocultar (botón Ver más / Ver menos).
- Tarjetas de proyectos organizadas con CSS Grid.
- Formulario de contacto con validación de nombre, email y mensaje.
- Contador de caracteres en tiempo real en el campo Mensaje.

## Cómo visualizar el proyecto
Abrir el archivo `index.html` en cualquier navegador web.
